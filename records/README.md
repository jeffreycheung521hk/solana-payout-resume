# 流程紀錄

這個目錄保存一輪真實協作留下的紀錄：使用者的原始請求與選擇、形狀卡與決策包的原文、使用者的裁決、寫回回執，之後還會有交接與審查包。

Notes 原本把這些放在不進 Git 的草稿目錄或聊天裡。本範例為了讓讀者看到流程，才把它們納入版本控制。設計結論以 `planning/docs/` 為準，這裡只記錄過程。

| 檔案 | 內容 |
|---|---|
| [01-opening.md](01-opening.md) | 原始請求、使用者的選擇與本輪分工 |
| [02-shape-card.md](02-shape-card.md) | 形狀卡原文與裁決 |
| [03-decision-pack.md](03-decision-pack.md) | 第一個決策包原文與呈現前的檢查 |
| [receipts.md](receipts.md) | 每次寫回的回執 |
