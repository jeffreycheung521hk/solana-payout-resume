# 主題索引

維護指令體系時才讀。一般任務按 `planning/AGENTS.md` 的觸發表載入主題，不讀這份。

| 主題 | 涵蓋 | 對應 Notes 章節 |
|---|---|---|
| `topics/workspace.md` | repo 邊界、從根目錄啟動、交流語言 | §2、§3.1 |
| `topics/line.md` | 線的須知、開場提示清單、交接清單 | §4、§6、附錄 A、附錄 B |
| `topics/design-collab.md` | 形狀卡、決策包、呈現前檢查、讀回覆、確認後驗證、寫回與回執、待辦帳本 | §7 |
| `topics/docs.md` | 讀者文件格式、結論狀態、只留最新基線、工程痕跡 | §10.1–10.3 |
| `topics/terminology.md` | 術語表格式、用名字的規則、命名規則、改名與入表 | §9 |
| `topics/code-review.md` | 實作分工、按批合併、審查節點與審查包、設計本身的複核 | §8 |
| `topics/verification.md` | 完成前的檢查與腳本 | §10.4–10.5 |
| `topics/instructions.md` | 指令體系的結構、主題寫法與七項核對 | §3 |

檢查腳本在 `scripts/`，用法見 `topics/verification.md`。
